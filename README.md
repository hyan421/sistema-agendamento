# sistema-agendamento
Projeto de um sistema de agendamento de serviços

* *Fernando De Jesus Teixeira Gonçalves Filho* — Full Stack (Foco em backend e banco de dados)

* *Objetivo do Sistema:*
Desenvolver uma plataforma web inteligente para o agendamento centralizado de serviços gerais (como estética, manutenção, consultorias e reparos). O sistema otimiza a conexão entre prestadores e clientes por meio de automação, gestão de horários em tempo real e um assistente integrado com inteligência artificial para recomendar serviços, tirar dúvidas e sugerir os melhores horários de atendimento de forma conversacional.

* *Tecnologias:*
* *Linguagem:* C# (.NET) / JavaScript (Node.js) ou Python
* *Frameworks:* React / Next.js (Frontend) e ASP.NET Core / Express (Backend)
* *Banco de Dados:* PostgreSQL ou MongoDB
* *Agentes de IA:* OpenAI API / LangChain para o assistente virtual inteligente

* *Histórias de Usuário:*
1. Como cliente, quero me cadastrar e fazer login na plataforma para gerenciar meus agendamentos e dados pessoais.
2. Como cliente, quero buscar por serviços disponíveis filtrando por categoria, preço e localização para encontrar o que preciso.
3. Como cliente, quero visualizar os horários livres de um prestador e agendar um serviço de forma rápida.
4. Como cliente, quero conversar com um agente de IA para tirar dúvidas sobre serviços e receber recomendações personalizadas.
5. Como prestador, quero cadastrar e gerenciar os serviços que ofereço, definindo duração e valor.
6. Como prestador, quero configurar minha agenda e horários de atendimento disponíveis para evitar conflitos de horário.
7. Como usuário (cliente ou prestador), quero receber notificações de confirmação, lembretes e alterações de agendamento.
8. Como administrador, quero visualizar métricas gerais da plataforma (número de agendamentos, usuários ativos e volume de serviços) em um painel de controle.
